# BuildPath — тарифы и лимиты

**Статус:** реализовано без онлайн-оплаты (ноябрь 2026). Лимиты — продуктовые правила в `builder-back/src/billing/plans.ts`, каталог `1.0.0`. Цены и ссылка для связи меняются сотрудником в консоли администратора.

## Тарифы

| | Бесплатный | Старт | Бизнес |
|---|---|---|---|
| Проекты (не в архиве) | 2 | 5 | 25 |
| Запросы к ИИ в месяц | 30 | 300 | 1500 |
| Опубликованные сайты | 1 | 3 | 15 |
| Приглашение специалистов | нет | да | да |
| Цена (стартовая, меняется в консоли) | бесплатно | 4 990 ₸ в месяц | 14 990 ₸ в месяц |

## Правила

- Лимиты считаются для аккаунта-владельца проектов. Запросы к ИИ, которые делают приглашённые специалисты, расходуют лимит владельца. Черновики по шаблону не считаются.
- Счётчик ИИ обнуляется 1-го числа каждого месяца (UTC).
- Проверки на сервере: создание и возврат проекта из архива, генерация ИИ, публикация нового сайта (обновление уже опубликованного разрешено всегда), приглашение специалиста.
- Когда лимит превышен (например, после окончания платного тарифа), всё созданное продолжает работать: сайты открываются, заявки приходят, проекты доступны. Запрещено только создавать новое сверх лимита.
- Проект можно отправить в архив (кроме опубликованного): он доступен только для чтения, не считается в лимите проектов, доступ специалистов отзывается.

## Оплата сейчас

Онлайн-оплаты нет. Клиент нажимает «Написать о тарифе» и открывает ссылку для связи, оплачивает по счёту, сотрудник с ролью `super_admin` назначает тариф в консоли (раздел «Customer plans») с необязательной датой окончания и номером платежа. Каждое изменение пишется в журнал сотрудников (`account.plan_assigned`).

## Цены в консоли

- Раздел «Plan prices» в консоли: цена «Старт» и «Бизнес» в тенге за месяц (целое число от 100 до 10 000 000; пусто — «Цена по запросу») и ссылка для связи (https://, например Telegram или WhatsApp, или mailto:).
- Менять может только `super_admin`, смотреть — ещё и `operations_auditor`. Каждое изменение пишется в журнал: `plan.price_changed` (тариф, старая и новая цена), `billing.contact_changed`.
- Новая цена сразу видна клиентам на странице тарифа. Уже назначенные тарифы не меняются: цена пока только для показа, списаний нет.
- Стартовые цены 4 990 ₸ и 14 990 ₸ подставлены как разумное начало для Казахстана, их нужно проверить.
- Ссылка из консоли важнее `SALES_CONTACT_URL`; переменная окружения нужна только для новой установки. Пока ссылки нет, кнопки «Написать о тарифе» у клиента нет.
- Лимиты по-прежнему в коде (`plans.ts`), в консоли только показываются.
