# Что проверить юристу

Документы 1.0 опубликованы с решениями по умолчанию. Здесь — что решено самостоятельно и что стоит подтвердить.

| Вопрос | Как решено сейчас |
|---|---|
| Одна отметка или несколько при регистрации | Одна обязательная отметка; текст прямо называет трансграничную передачу и получателей. |
| Достаточно ли согласия для передачи в OpenAI и Resend или Brevo (ст. 16 Закона № 94-V) | Передача по согласию; ИИ можно не использовать. Отключения ИИ на уровне аккаунта нет. |
| Локализация (ст. 12) | База и копии в РК; зарубежным исполнителям уходят только данные, нужные для функции. |
| Уведомление и реестр (ст. 10-1, с 25.08.2026) | Не подаём: по открытым источникам обязанность у операторов от 500 000 субъектов. |
| Заявки посетителей сайтов | Оператор — владелец сайта; поручение на обработку — пункт 8.2 оферты. |
| Закон «Об искусственном интеллекте» (№ 230-VIII) | Черновики ИИ помечены в интерфейсе; на опубликованном сайте пометки нет. |
| Срок хранения после удаления аккаунта | 30 дней по умолчанию, меняется в админке (1–90). В резервных копиях — ещё до 14 дней. |
| Сроки ответа на запросы и уведомления об утечке | «В сроки, установленные законом», без конкретных чисел. |
| Возврат денег | За неиспользованные полные месяцы, в течение 10 рабочих дней по письму. |
| Ограничение ответственности | Только для предпринимателей и организаций (3 месяца оплаты); для потребителей — по закону. |
| Подсудность | Потребитель может обратиться в суд по месту жительства. |
| Редакция на казахском языке | Нет. |
| Регистрация ТОО/ИП, ОКЭД, налоговый режим | Вне документов; нужно до приёма оплаты. |

## Оплата работы специалистов через BuildPath

Платформа принимает оплату от владельца проекта и переводит её специалисту (за вычетом комиссии, если она задана). Нужно проверить, не делает ли это BuildPath платёжным агентом по законодательству РК, какой договор нужен со специалистами (агентский, поручения) и как учитывать налоги. Подробнее — docs/PAYMENTS.md.

## Голосовые сообщения в боте

Распознавание речи (переменная `BUILDER_AI_TRANSCRIBE_MODEL`) отправляет запись голоса в OpenAI (США). Бот спрашивает отдельное разрешение перед первым голосовым и не хранит запись, но в политике конфиденциальности 1.1 такой передачи нет. До включения в production добавить её в таблицу передач (что: запись голоса; когда: только после разрешения в боте; хранение: не хранится, остаётся распознанный текст) и выпустить новую версию политики. Голос может считаться биометрическими данными — проверить с юристом.
